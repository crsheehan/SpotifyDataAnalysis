## Spotify Explorator Data Analysis  
**Overview**  
I created this project to explore and analyze trends and patterns in Spotify's songs using exploratory data analysis. The goal is to understand how various audio features relate to a song's popularity for artists and labels to be able to produce well-performing songs.  
  
**Research questions**
This project investigates the following questions:  
1. What audio features have the biggest association with a song's popularity?
2. Do instrumental tracks differ in popularity from vocal tracks?
3. Do explicit songs perform better than non-explicit songs?
4. Do songs with different genres differ in popularity?
5. What does the distribution of song popularity look like on Spotify, and what does this imply for analysis?
6. Have song length or other features changed over time?

**Dataset**  
- Source: Spotify song dataset (CSV format)
- Contents: Track-level data including various audio features, popularity scores, genre labels, and more
- Size: The Dataset contains thousands of songs spanning multiple genres.

**Tools and Technologies**  
- Python
- pandas - data cleaning and handling
- matplotlib, seaborn - data visualizaiton
- Jupyter Notebook - data analysis and documentation

**Key Takeaways**  
- A song's popularity on Spotify is heavily skewed, with most tracks having a low popularity score.
- Certain audio features show a stronger correlation to popularity than others, though no single feature can be used to determine a song's success.
- genre, explicit content, and instrumentalness can influence popularity, but don't determine it.  
These findings demonstrate the complexity of music popularity and the importance of analysis.

**Future Work**  
- Build predictive models for song popularity
- Incorporate additional data, such as release years, to analyze changes in trends over time
- Explore clustering songs based on audio features.
